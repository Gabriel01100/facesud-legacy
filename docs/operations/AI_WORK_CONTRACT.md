# Contrato de trabajo con asistentes de IA

Antes de editar: leer documentación, inspeccionar rama/estado real, delimitar archivos y proponer plan para cambios de arquitectura, seguridad o datos.

Durante: respetar alcance, hacer cambios pequeños, justificar dependencias, no agregar secretos/datos reales, no ejecutar acciones destructivas ni integrar servicios no autorizados.

Al finalizar informar archivos cambiados, decisiones, pruebas realmente ejecutadas, pruebas no ejecutadas, riesgos y pasos manuales.

Nunca afirmar tests, despliegues, integraciones o autorizaciones que no se verificaron. No implementar número de miembro, mensajería privada, marketplace, anuncios, pagos ni verificación institucional en tareas del MVP.
